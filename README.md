# Meme Sprint 3: AI Agent Goes Rogue

A program that draws one meme image about an AI agent that has gone rogue.

The joke: an AI agent asked to fix one bug "fixes" it by deleting the entire app — "No app, no bug."

Run `python3 main.py` to write `entry.png` (1024x1024, pure Python stdlib, deterministic).
